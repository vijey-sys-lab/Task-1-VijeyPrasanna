What We Built

Three Pillars of Execution

Following the DecodeLabs framework — Strategy, Visual Design, and Implementation — every pixel has purpose.

🗺️

Strategy & Blueprint

Empathy-mapped user research and low-fidelity wireframing. We never guess — we design from evidence and hierarchy.

🎨

2025 Visual Design

Mocha Mousse warmth, Ethereal Blue trust, and Moonlit Grey refinement. Typography strictly limited to 2 families, 3 weights.

⚙️

Semantic HTML5

Every element earns its place. Header, nav, main, article, footer — structural landmarks for screen readers and AI crawlers.

📐

CSS Grid + Flexbox

Grid for macro layouts (the 2D floor plan), Flexbox for micro components. Mobile-first with fluid clamp() typography.

📱

Mobile-First Responsive

Single column base, expanding at 768px (tablet) and 1024px (desktop) via min-width media queries. Zero layout breaks.

♿

WCAG Accessibility

Skip links, ARIA labels, focus-visible indicators, role attributes, and reduced-motion support. Code for everyone.

The Roadmap

How This Was Built

Following DecodeLabs' 6-phase execution framework from the brief — no step skipped.

  1. 1

    Discovery

    Define "How Might We" — understand the user problem before touching code.

  2. 2

    Wireframe

    Grayscale, mobile-first. If it doesn't work in grayscale, color won't fix it.

  3. 3

    Semantics

    HTML5 landmarks — header, nav, main, article, footer. Accessibility bedrock.

  4. 4

    Style

    CSS Grid, Flexbox & the 2025 palette. Warm, grounded, readable at all sizes.

  5. 5

    Logic

    Vanilla JS for state management — mobile menu, scroll reveals, counter animations.

  6. 6

    Audit

    LCP/CLS checks, accessibility pass, semantic integrity verified.
